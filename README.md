## ⚡ Key Highlights
* **Immersive 3D Graphics:** Integrated WebGL/Three.js spatial elements optimized for 60fps performance.
* **Fluid Micro-Interactions:** Smooth scroll choreography and transitions powered by modern animation libraries.
* **Responsive Architecture:** Fully adaptive UI engineered across desktop, tablet, and mobile displays.
* **Clean Code Structure:** Modular component layout with maintainable design token systems.

---

## 🛠️ Tech Stack & Tooling
* **Frontend:** React.js, Next.js, TypeScript, Tailwind CSS
* **3D / Motion:** Three.js, WebGL, GSAP / Framer Motion
* **Deployment & CI/CD:** Vercel

## 🚀 Local Setup & Installation

Clone the repository and run locally:

```bash
# 1. Clone repository
git clone [https://github.com/sipten-labs/sipten-portfolio.git](https://github.com/sipten-labs/sipten-portfolio.git)

# 2. Navigate into project directory
cd sipten-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
